# 界面设计规范

## 设计目标

界面面向需要长期整理个人收藏的用户，应保持安静、清晰和高信息密度。功能入口按任务分区，避免把统计、浏览、同步和标签管理堆叠在同一页面或临时弹窗中。

## 信息架构

侧边栏提供四个一级区域：

- “总览”：查看归档规模、媒体完整率、标签覆盖和近期归档趋势。
- “我的收藏”：搜索、筛选、排序、分页、查看媒体、打标签和删除推文。
- “同步中心”：查看本地存储位置、同步状态、媒体进度、失败项和停止阈值。
- “标签管理”：创建、重命名、改色和删除本地标签。

切换区域时保留当前收藏筛选条件、页码和合理的滚动状态。页面右下角提供返回顶部按钮，在内容接近顶部时隐藏。

## 总览

- 指标使用统一的等宽数字特性或规整数字字体，避免位数变化造成跳动。
- 统计值、单位和解释文字应有明确层级，标题字号不得接近营销页英雄标题。
- 没有数据时显示零值和简洁空状态，不用虚构示例数据填充。
- 统计卡片只承载独立指标，不在卡片内部嵌套其他卡片。

## 我的收藏

- 筛选栏包括关键词、媒体类型、标签、起始日期、截至日期、排序字段和排序方向。
- 日期输入旁统一显示“年/月/日”，并分别标明“起始日期”和“截至日期”。
- 媒体类型包括所有媒体、图片、视频和纯文本。
- 排序字段包括发布时间、收藏时间和作者名称，并可选择正序或逆序。
- 每页数量选择和分页控件同时出现在内容列表上方与下方，两处状态必须同步。
- 分页提供上一页、下一页、多个相邻页码和页码输入，便于跨越多页。
- 卡片展示作者显示名称、`@账号名`、发布时间、正文、标签、媒体和原始链接入口。
- 原始 X 链接作为独立操作展示，不拼接到正文文本中。

## 标签交互

- 标签使用颜色标识，但不能只依赖颜色表达选中或分类状态。
- 在卡片内新增或移除标签时只刷新该卡片的标签区域，不重建整个列表。
- 标签操作后保持当前页码和滚动位置。
- 如果移除的标签正是当前筛选条件，允许刷新列表以移除不再匹配的卡片，并将页码限制在有效范围内。
- 标签管理是独立页面，不使用阻塞式弹窗承载完整管理流程。

## 批量删除

- 进入多选状态后，选择框、已选数量和删除按钮位置保持稳定。
- 删除前明确提示会同时删除正文、链接、标签关联、原始响应和媒体文件。
- 成功后刷新总数和当前结果；当前页为空时退回最后一个有效页。
- 失败时保留未确认删除的卡片和选择状态，并显示错误原因。

## 图片查看器

- 点击图片在全屏遮罩查看器中打开。
- 提供关闭、放大、缩小、左旋、右旋和复位按钮；使用熟悉的图标并提供可访问名称。
- 图片首次打开时按视口缩放并在水平和垂直方向居中，长图不得只显示顶部。
- 缩放后允许平移查看细节，旋转后重新计算可视范围。
- `Escape` 关闭查看器；背景滚动在查看器打开时锁定，关闭后恢复。

## 状态反馈

同步中心失败面板标题区提供“全部重试”，每条失败记录提供“重试”。按钮在 `starting`、`collecting`、`downloading`、`retrying` 状态或请求提交期间禁用；面板同时显示提交、完成和错误消息。“全部重试”只针对 `failed`，不受列表显示上限影响。

- 同步采集和媒体下载分别使用进度条、数量和文字状态。
- 启动、停止、完成、失败和等待登录等状态必须可区分。
- 保存位置使用可换行的等宽文本展示，不能因长路径撑破布局。
- 空状态、加载状态和错误状态占用稳定空间，避免列表明显跳动。
- 操作反馈放在相关控件附近，不用浏览器原生警告框替代页面状态。

## 排版与视觉约束

- 默认正文优先使用系统中文无衬线字体；数字使用支持表格数字的字体与 `font-variant-numeric: tabular-nums`。
- 不使用负字距，不按视口宽度连续缩放字体。
- 按钮、分页项和工具栏控件具有稳定尺寸，内容变化不能推动相邻元素。
- 页面以中性背景和清晰分隔为主，避免单一色系覆盖全部层级。
- 卡片圆角保持克制，不在卡片内再嵌套卡片。

## 响应式

- 桌面端优先支持连续筛选、分页和批量操作。
- 窄屏下侧边栏可收纳，筛选控件允许分行，但标签和按钮文字不得溢出。
- 推文媒体使用明确的宽高约束，图片加载不能改变工具栏和分页位置。
- 查看器工具栏在移动视口内保持可操作，图片不得遮挡关闭按钮。

## 可访问性

标签筛选使用复选框面板和“全部满足／任一满足”分段控件；面板在窄屏内不得超出视口。同步扩展弹窗显示刷新提示、翻页间隔设置和当前状态。

- 所有表单控件都有可见标签或准确的 `aria-label`。
- 图标按钮有可访问名称和悬停提示。
- 键盘可以到达导航、筛选、分页、标签、删除和查看器控件。
- 当前页面、选中标签、忙碌状态和错误消息通过语义或 ARIA 属性表达。
- 文本与背景保持足够对比度；焦点状态清晰，不以颜色作为唯一提示。
- 动画尊重 `prefers-reduced-motion`，关键操作不依赖动画完成。

## 界面变更检查表

- 在桌面和移动宽度检查文字溢出、重叠和布局跳动。
- 验证顶部与底部分页同步。
- 验证非第一页标签操作保持页码和当前位置。
- 验证日期提示统一为年月日。
- 验证长图首次打开居中，缩放、旋转和复位可用。
- 验证空归档、媒体失败和接口错误状态。
