# Chrome 扩展采集规范

扩展只在用户点击“刷新并开始同步”后工作。它连接当前已登录的 Chrome 标签页，刷新目标账号的 Likes 页面，监听刷新后产生的 Likes GraphQL 网络响应，并自动平滑向下滚动以触发后续请求。

扩展不读取推文 DOM，不提交 DOM 批次，也不提供不刷新续采。这样可以避免视频缩略图和 `blob:` 地址被误判为可下载媒体。

## 翻页速度

弹窗中的“翻页间隔”范围为 0.5 到 5 秒，默认 1.8 秒。设置保存在 Chrome 本地存储，修改后当前同步会立即使用新间隔。

## 生命周期

开始同步前必须确认当前标签页是目标账号的 Likes 页面。扩展等待页面加载完成后再注入滚动驱动；注入失败会自动重试。到达页面底部并连续多次没有新增高度后，扩展会通知服务完成采集并开始收尾下载。

## 错误处理

网络响应读取失败会显示在扩展状态中。媒体下载错误会进入同步中心，并包含推文 ID、作者、原文链接、媒体序号和具体原因。
