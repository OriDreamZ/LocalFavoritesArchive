# 安全、隐私与限制

## 使用边界

本项目用于归档用户本人账号当前有权访问的 X Likes 内容。使用者必须自行遵守 X 的服务条款、内容权利要求和所在地法律。项目不授权获取、保存或传播无权访问的内容。

## 本地隐私

- 本地服务默认只监听 `127.0.0.1`，不向局域网或互联网开放。
- 推文、作者、媒体、原始响应和标签保存在用户指定的本地归档目录。
- 项目不包含云同步、遥测或第三方分析服务。
- 归档可能包含敏感兴趣、已删除内容或受版权保护媒体，应按私有数据保护。
- 操作系统备份、同步盘和杀毒软件仍可能复制或扫描归档，用户需自行配置这些外部工具。

## 浏览器权限

Chrome 扩展申请：

- `activeTab`：仅对用户当前选择的标签页执行同步。
- `debugger`：读取 Likes 页面相关网络响应；Chrome 会显示标签页正在被调试。
- `scripting`：在当前页面执行受控滚动和状态读取。
- `storage`：保存扩展同步会话和界面状态。

主机权限限定为 `x.com`、`twitter.com` 和本机 `127.0.0.1:8765`。新增权限必须在代码、清单和本文档中同时说明。

## 登录与访问控制

程序使用用户已经正常登录的 Google Chrome，不保存 X 密码，也不启动带 `--no-sandbox` 的自动化浏览器。遇到登录验证、验证码、异常活动提示或账号限制时，应由用户在 Chrome 中正常处理。

程序不得尝试绕过登录验证、访问控制、速率限制、反自动化或反滥用机制。无法访问的页面或平台未返回的数据不属于可采集范围。

## 本地服务安全

- 默认绑定地址保持为 `127.0.0.1`。
- 当前 API 没有面向远程访问设计的身份认证，不应直接暴露到局域网、公网或反向代理。
- 媒体读取和删除必须验证解析后的路径仍位于归档根目录内。
- 接收的 JSON 和数字设置需要执行类型与范围验证。
- 错误消息不应向扩展或页面泄露不必要的系统路径、请求头或浏览器会话信息。

## 网络与媒体风险

显式重试不扩大访问权限，不绕过登录、隐私或平台限制。媒体链接过期、需要额外权限、网络异常或 X 响应结构变化时，重试仍可能失败；服务重启不会自动重试。

媒体下载器会访问 X 响应提供的媒体地址。实现必须限制协议和合理的并发，不执行下载内容。浏览器展示本地媒体时依赖浏览器自身解码器；未知或损坏文件应标记失败，不能作为 HTML 或脚本注入页面。

原始响应和来源 URL 可能包含短期参数或用户相关信息，不应复制到日志、公开问题或测试样本中。

## 数据删除风险

单条删除、批量删除和彻底清空均不可恢复。执行前应确认目标、停止写入并保留需要的备份。文件删除只能针对经过归档根目录所有权检查的具体路径，禁止对项目根目录、用户目录或未解析变量执行递归删除。

## 平台兼容风险

本项目依赖 X 网页和内部响应的当前结构，而这些接口不是面向第三方工具的稳定公开 API。字段名、时间线指令、媒体地址、登录流程或调试协议行为发生变化时，采集可能部分或完全失效。

兼容性问题应通过最小、去标识化样本修复。不能以扩大权限、绕过验证或高频请求作为默认解决方案。

## 已知限制

局域网访问默认关闭。`--lan` 开启后不进行身份验证并授予完整管理权限，任何同网段设备都可以永久删除内容，因此只能在可信网络使用；不得进行公网端口映射。

- 无法保证获得账号全部历史 Likes，只能保存时间线实际返回的内容。
- 被删除、取消喜欢、受地域或账号限制的内容可能无法获取。
- 引用推文、长文、卡片、直播或新媒体类型的字段可能需要后续适配。
- 视频可用清晰度取决于响应中提供的候选地址和下载选择逻辑。
- 当前主要验证环境为 Windows 和 Google Chrome，其他系统或 Chromium 浏览器不保证兼容。
- 本地服务没有多用户隔离和远程认证能力。
- 归档数据库没有内置加密；磁盘加密和访问权限由操作系统负责。
- X 改版后扩展可能捕获到响应但解析不到推文，或只能保存部分字段。

## 问题报告

报告问题时可以提供程序版本、操作系统、Chrome 版本、错误文字和去标识化的字段结构。不得提交真实 Cookie、授权头、账号 ID、推文正文、私有媒体 URL、完整原始响应或整个归档数据库。
