# 功能说明

## 项目定位

Local Favorites Archive 是一个非官方、本地优先的 X 喜欢内容归档工具。它通过用户已经登录目标账号的 Google Chrome 读取当前 Likes 页面实际返回的数据，将推文文本、作者信息、发布时间、原始链接及图片或视频保存到本地。

程序不依赖 X 官方收费 API，不向第三方归档服务上传数据。它只处理当前账号在正常登录状态下有权访问、且 X 页面实际返回的内容。

## 采集与同步

- Chrome Manifest V3 扩展附加到当前打开的 X Likes 标签页，读取相关网络响应。
- 扩展将响应发送到本机 `http://127.0.0.1:8765`，由本地服务解析和持久化。
- 同步中心分别显示推文采集进度和媒体下载进度。
- 同步可以手动停止，也可以在连续遇到 N 条本地已有推文后自动停止。
- N 为 `0` 时禁用连续已有停止条件，扩展会继续滚动至当前时间线末尾或由用户停止。
- 推文 ID 是唯一标识；重复同步不会重复保存推文，也不会重复下载已成功保存的媒体。
- 媒体下载失败会记录失败状态，可通过同步中心或 `local-favorites retry-media` 重试。

### 媒体显式重试

同步期间的隐式重试发生在每批响应和采集结束时；同步完成后没有定时自动重试，服务重启也不会自动重试。同步中心提供“单条重试”和“全部重试”，仅处理 `failed` 媒体；命令行 `local-favorites retry-media` 会处理全部未下载媒体，包括 `failed` 与 `queued`。

## 本地归档

每条推文可以保存以下信息：

- X 推文 ID 和原始链接；
- 完整可见正文；
- 发布者显示名称、带 `@` 的账号名和作者 ID；
- 发布时间、采集时间及可用的语言信息；
- 正文中的普通链接；
- 图片、视频及其尺寸、时长、下载状态等元数据；
- 用于兼容性排查的原始响应片段。

程序不保存点赞数、转发数、回复数等互动计数。推文自带媒体在成功本地化后通过本地媒体展示，正文中不重复显示媒体短链接；正文中的其他普通链接继续保留。

## 浏览与排序

“我的收藏”支持：

- 按关键词搜索正文、作者显示名称或账号名；
- 按图片、视频或纯文本筛选；
- 按本地标签筛选；
- 按起始日期和截至日期限定发布时间；
- 按发布时间、收藏时间或作者名称排序；
- 对每个排序字段选择正序或逆序；
- 选择每页条数，通过顶部和底部分页器换页或输入页码跳转；
- 从卡片打开 X 原始链接。

## 媒体查看

- 图片可以在查看器中打开大图。
- 查看器支持放大、缩小、旋转和复位。
- 长图首次打开时在可视区域中完整居中，不固定到图片顶部。
- 视频使用浏览器原生播放控件播放本地文件。
- 媒体文件缺失或下载失败时显示状态，不用破损资源替代正文。

## 标签管理

- 标签完全保存在本地，不会写回 X。
- 可以创建、重命名、修改颜色和删除标签。
- 可以在推文卡片上添加或移除标签。
- 删除标签不会删除推文。
- 在非第一页修改标签时保留当前页码和当前位置；如果移除当前筛选条件对应的标签，则列表会刷新以反映结果变化。

## 删除与去重

- 支持永久删除单条推文。
- 支持勾选多条推文并批量永久删除。
- 删除同时清理该推文的正文、标签关联、链接、原始响应和本地媒体。
- 删除操作不可恢复，界面必须在执行前明确提示影响范围。
- 后续同步再次遇到已删除但仍被账号喜欢的推文时，会将它作为新内容重新归档。

## 功能边界

- 能获取的范围取决于 X Likes 时间线当时实际返回的内容。
- X 页面和内部响应结构变化后，采集解析可能需要适配。
- 被删除、取消喜欢、受访问限制或未由平台返回的历史内容无法保证获取。
- 账号验证、异常活动提示或访问限制必须由用户在 Chrome 中正常处理。
- 当前主要支持 Windows、Google Chrome 和 Python 3.11 及以上版本。

## 非目标

- 不绕过登录验证、访问控制、反滥用措施或平台限制。
- 不提供批量抓取他人私有内容的能力。
- 不将本地标签或删除操作同步回 X。
- 不保证完整恢复 X 未返回的历史 Likes。
- 不作为互动数据分析、账号运营或社交指标统计工具。

## 新增采集与访问模式

标签筛选支持多个标签的交集和并集；扩展支持从当前 Likes 页面位置继续或从头重新同步；服务支持显式开启局域网完整管理模式，默认关闭且无身份验证。
