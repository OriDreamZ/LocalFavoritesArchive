# 收藏顺序网格列数实施计划

> **供自动化开发执行：** 按任务逐项完成，并在每项完成后运行对应验证。

**目标：** 在“我的收藏”中提供 1 至 4 列的顺序网格显示，同时保持推文从左到右、再从上到下的阅读和排序顺序。

**实现方式：** 使用既有 `#posts` CSS Grid 容器，通过 CSS 自定义属性控制列数；JavaScript 负责点击切换、保存至浏览器本地设置并在启动时恢复。窄屏媒体查询强制单列，防止卡片过窄。

**技术栈：** 原生 HTML、CSS、JavaScript；Python pytest 静态页面回归测试。
