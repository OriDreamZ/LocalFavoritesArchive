# 数据存储规范

## 默认目录

默认归档根目录为启动命令当前目录下的 `archive/`：

```text
archive/
├── archive.sqlite3
├── raw/
└── media/
```

- `archive.sqlite3`：结构化推文、媒体、链接、标签、设置和同步记录。
- `raw/`：按推文保存的原始响应数据，用于重新解析和兼容性排查。
- `media/`：按推文组织的本地图片和视频。

可通过 `--archive D:\路径\到\归档` 指定其他根目录。服务页面显示实际解析后的绝对路径。

## 数据库表

- `posts`：以 `post_id` 为主键的推文正文、作者、时间、原始链接和响应路径。
- `media`：以 `(post_id, media_index)` 为主键的媒体来源、本地路径、类型、尺寸、状态和错误。
- `post_links`：正文中的普通链接，记录显示地址、展开地址和短链接。
- `sync_runs`：每次同步的开始、结束、状态和计数。
- `archive_settings`：归档级设置，目前包含连续已有停止阈值。
- `tags`：本地标签名称、颜色和创建时间。
- `post_tags`：推文与标签的多对多关系。
- `posts_fts`：用于正文和作者搜索的全文索引。

数据库连接启用外键约束。初始化时 `archive_settings` 会包含默认设置，因此空归档不要求该表记录数为零。

## 推文主键与去重

X 推文 ID 保存为 `posts.post_id`，是本地唯一主键。每次采集都先按该 ID 判断：

- 新 ID：保存推文、链接、原始响应和媒体任务。
- 已有 ID：不重复创建推文，不重复下载已成功保存的媒体，并更新必要的发现状态。
- 同一响应中重复出现：在写入前和数据库层共同去重。

同步停止阈值统计连续出现的已有推文。遇到新推文时连续计数归零；阈值为 `0` 时不根据已有内容自动停止。

## 正文与链接规则

- `posts.text` 保存用户在 X 页面可见的正文语义，不在末尾附加原始推文链接。
- 推文原始链接单独保存在 `posts.url`，由界面提供跳转入口。
- 正文中的普通链接保存到 `post_links`，本地展示时仍可点击。
- 图片和视频对应的 X 媒体短链接在媒体被识别后不作为普通正文链接重复展示。
- 引用或回复关系在可取得时保存 ID，但不保证被引用内容一定同时存在于本地。

## 媒体状态

媒体初始状态为 `queued`，下载成功后记录本地相对路径、MIME 类型、文件大小和校验值；失败时保留来源地址和错误信息。界面只通过本地 `/media/` 路由访问已下载文件。

文件路径必须保存为归档根目录下的受控相对路径。读取和删除时重新解析并检查目标仍位于归档根目录内，防止路径越界。

## 原始响应

原始响应用于平台字段变化时排查解析结果，可能包含正文、作者和公开页面返回的其他字段。它与结构化数据一样属于用户私有归档，不应提交 Git、上传问题报告或公开分享。报告缺陷前必须删除账号标识、推文内容、媒体地址和会话相关信息。

## 删除语义

单条或批量删除是永久操作。删除一条推文时应同时处理：

- `media`、`post_links`、`post_tags` 和全文索引记录；
- `posts` 主记录；
- 对应的原始响应文件；
- 对应的本地媒体目录。

标签本身不会因为删除某条推文而删除。删除标签只移除标签和关联，不删除推文。删除后的推文如果仍存在于 X Likes，后续同步可能重新归档。

## 持久化与迁移

归档目录不会在服务重启时清空。`ArchiveStore` 每次启动会确保目录和已有表存在，当前采用向前兼容的 `CREATE TABLE IF NOT EXISTS` 初始化方式。新增字段或修改约束时必须提供明确迁移方案和旧库测试，不能要求用户静默删除数据库。

## 备份与恢复

备份前停止本地服务和扩展同步，然后完整复制归档根目录。只复制数据库而遗漏 `media/` 或 `raw/` 会产生不完整备份。

恢复步骤：

1. 确认本地服务已停止。
2. 将完整备份放回原归档路径，或使用 `--archive` 指向备份目录。
3. 启动服务并检查总览数量、媒体完整率和失败列表。
4. 对未完成媒体执行 `local-favorites retry-media --archive <归档路径>`。

不要在服务运行时覆盖 SQLite 文件或合并两个归档目录。当前没有自动合并不同数据库的功能。

## 彻底清空

彻底清空会删除全部推文、媒体、标签、同步记录和原始响应，且不可恢复。正确流程是停止服务、验证目标路径、删除整个归档根目录，再运行：

```powershell
local-favorites init --archive .\archive
```

初始化后的空归档包含数据库结构、默认设置以及空的 `raw/` 和 `media/` 目录。
